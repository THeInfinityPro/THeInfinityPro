## 🚀 Featured Project

### 🔧 DevOps Auto Installer

A Bash-based automation platform for setting up and managing a complete DevOps environment on Ubuntu.

<p align="center">
  <a href="https://github.com/THeInfinityPro/devops-auto-installer">
    <img src="https://img.shields.io/badge/View_Project-DevOps_Auto_Installer-2ea44f?style=for-the-badge&logo=github" />
  </a>
</p>

### 🧰 Includes

* 🐳 Docker installation and configuration
* ☸️ Kubernetes and `kubeadm`
* 🌐 Kubernetes cluster initialization
* 🔧 Jenkins installation
* 📊 Prometheus installation
* 📈 Grafana installation
* 🔍 Installation verification
* ❤️ System health checks
* 🖥️ Interactive system dashboard
* 🗑️ Component and complete environment removal
* 📝 Installer logging
* ⚙️ Modular Bash architecture
* ✅ GitHub Actions Bash validation
* 🖥️ Interactive Whiptail interface

### 🏗️ Architecture

```text
                    USER
                      │
                      ▼
                install.sh
                      │
                      ▼
             Whiptail Interface
                      │
        ┌─────────────┼─────────────┐
        │             │             │
        ▼             ▼             ▼
   INSTALLATION   VERIFICATION   UNINSTALL
        │             │             │
        ▼             ▼             ▼
     Docker       Health Check    Docker
   Kubernetes     Dashboard     Kubernetes
     Jenkins      Validation       Jenkins
   Prometheus                    Prometheus
     Grafana                       Grafana
        │
        ▼
   Installer Logs
```
